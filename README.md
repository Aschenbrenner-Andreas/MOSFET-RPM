# MOSFET RPM – Drehzahl-Messlabor

Drehzahl- und Gleichlaufmessung für Plattenspieler, direkt im Handy-Browser.

**App:** https://aschenbrenner-andreas.github.io/MOSFET-RPM/

- **Teller (Gyroskop):** Handy auf die Platte legen, Drehzahl über ganze Umdrehungen gemittelt
- **Messton (Mikrofon):** 3150/3000/1000/440 Hz, absolute Drehzahl plus Wow & Flutter (bewertet und unbewertet)
- **Kalibrierung:** Gyro-Nullpunkt und Gyro-Skalierung per Messton
- **Umdrehungs-Signatur:** zeigt, ob die Abweichung von der Platte (Exzentrizität) oder vom Antrieb kommt

Am iPhone in Safari öffnen, Bewegungszugriff erlauben, dann „Zum Home-Bildschirm“. Messwerte bleiben auf dem Gerät.

Quelle: `tools/drehzahl/` im MOSFET-Repo.
